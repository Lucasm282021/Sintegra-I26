# Frontend ARBA — Sintegra I26

Frontend en React + Vite que consume el backend ARBA en `http://localhost:3003` mediante el proxy de Vite.

## Requisitos

- Node.js y npm instalados.
- Backend ARBA iniciado en el puerto 3003.

## Inicio

En PowerShell, desde esta carpeta:

```powershell
npm install
npm run dev
```

Abrí la dirección que muestre Vite, normalmente `http://localhost:5173`.

El backend debe estar activo en otra terminal. Docker no es necesario para probar este frontend.
