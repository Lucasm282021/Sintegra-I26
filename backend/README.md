# Backend unificado — Sintegra I26

Un solo backend para todo el ecosistema, con un módulo por sistema y una base PostgreSQL en Supabase. El diseño, las reglas para compartir datos y cómo aplicarlo están en [doc/BACKEND-UNIFICADO.md](../doc/BACKEND-UNIFICADO.md).

- `supabase/migrations/` — esquema de la base.
- `supabase/seed.sql` — datos de prueba ficticios.
